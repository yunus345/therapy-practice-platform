# AGENTS.md

Instructions for every coding agent working in this repository (GitHub Copilot, Codex, Claude Code and others).

**The full rules live in `CLAUDE.md`. Read it completely before any task and follow it as if it were written here.** Then read `PROGRESS.md` and the active spec in `docs/phases/`.

The most important rules, in short:

- Reply to the owner in **Turkish**. Everything written into the repository (code, comments, commits, docs) is in **English**; only user-facing UI text is Turkish, in the i18n message files.
- Work only on the active milestone of the active phase. **Present a plan and wait for approval** before writing code, and stop after each milestone.
- **Never write or edit** `CLAUDE.md`, `AGENTS.md`, `docs/phases/` or `.claude/settings.json`. Never write a phase spec yourself; if one is missing, stop and ask.
- **Design decisions belong to the owner.** Present options and wait before changing how the product looks or feels.
- Ask before adding, removing or upgrading dependencies, before pushing, and before deleting files or data.
- Commit finished work in small commits; never leave a milestone uncommitted.
- Keep `PROGRESS.md` accurate (newest log entry on top) and end every response that changed files with the Turkish summary described in `CLAUDE.md`.

`frontend/AGENTS.md` is generated by Next.js and only covers Next.js usage. It does not replace this file.
